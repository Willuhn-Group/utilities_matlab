# utilities_matlab

General-purpose MATLAB utilities for everyday data analysis and figure generation.

This repository collects small functions that I use across different neuroscience projects, including file management helpers and plotting utilities. The code is not tied to any specific experiment, and can be reused in other contexts.

## Features

- File management helpers (e.g. listing files, building paths, batch processing).
- Plotting utilities for quick data visualization.
- Small convenience functions that simplify common MATLAB tasks.

## Repository structure

```text
matlab-utils/
├─ file_utils/      % functions to work with files and folders
├─ plot_utils/      % plotting functions
├─ misc_utils/      % other general-purpose helpers
└─ examples/        % simple usage examples
